# Wacdo — Front-end (Borne de commande)

Bloc 1 du projet Wacdo : interface borne tactile pour passer une commande (catalogue, panier, récapitulatif).

## Statut

🚧 En cours de développement — mode JSON statique (voir `EPIC 2` du `BACKLOG.md` à la racine).

## Stack

- HTML5 sémantique
- CSS3 (media queries, responsive, cible principale 1920×1080)
- JavaScript vanilla (`fetch`/AJAX, pas de framework)

## Installation

Aucune dépendance à installer. Servir le dossier via un serveur local (ex. XAMPP/Apache) :

```
http://localhost/wacdo2/front/
```

## Structure des données

Les fichiers JSON statiques (`produits.json`, `menus.json`) sont utilisés en attendant l'API réelle du Bloc 2.
Leur structure est décrite dans `T01.5` du backlog et doit rester identique à celle renvoyée par l'API.
